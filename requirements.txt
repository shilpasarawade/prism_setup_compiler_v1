Task Objective
----------------------------------
Build a small module named: prism_setup_compiler_v1
The module should accept:

A setup definition in JSON or YAML
Historical market data in CSV format

And produce:

setup_validation_report.json
setup_score_log.csv
entry_intent_log.csv
trade_log.csv
backtest_summary.json
audit_log.json

Setup to Implement
Please implement the following setup:
Setup Name: Breakout Retest Acceptance
Setup Type: Directional
Direction: Long
Pod: POD-1 Structural Expansion


Entry Logic
---------------
Use a retest-based entry.
Rules:
Breakout level = previous 20-bar high
Retest zone low = breakout level − 0.10 × ATR
Retest zone high = breakout level + 0.10 × ATR
Retest midpoint = average of retest zone low and high
Entry triggers only if:
Prior breakout occurred
Price retests the zone
Close is above retest midpoint
Close is above VWAP
Close position is at least 0.60
Setup score is at least 6.5
Close position formula:
close_position = (close - low) / (high - low)
Stop Loss Logic
For long trades:

atr_stop = entry_price - ATR × atr_multiplier

structure_stop = retest_zone_low

stop_loss = min(atr_stop, structure_stop)

Use:

atr_multiplier = 1.2

Risk per unit:

R = entry_price - stop_loss

Reject the trade if R is less than or equal to zero.

Target Logic
Target 1:

T1 = entry_price + 1.5R

Target 2:

T2 = entry_price + 2.5R

Acceptance Filters
A setup should pass only if:

Liquidity score is at least 0.60

Volume ratio is at least 1.20

Spread percentage is less than or equal to 0.50%

MPS state is not BLOCK

Regime is allowed

Market state is allowed

Invalidation Rules
The setup or trade becomes invalid if:

Close moves back below breakout level

Regime becomes SHOCK

MSE state becomes TREND_DOWN

MPS state becomes BLOCK

Every invalidation must be logged with a reason code.

Re-entry Logic
Allow only one re-entry.

Re-entry is allowed only if:

Previous trade was stopped or expired

Setup score is at least 6.5

Regime has not degraded

Price enters the retest zone again

TTL condition is still valid

TTL Logic
If entry does not occur within 5 bars after breakout, the entry intent should expire.

If trade is open and neither target nor stop is hit within 20 bars, exit using TIME_EXIT.
